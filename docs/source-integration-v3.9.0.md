实现过程中实测发现并修复的问题（均已加回归测试）：

- 腾讯 K 线对北交所只返回最新 1 根日线，区间和分钟线为空（920021 / 920982 / 920185）。函数改为遇北交所直接报错，指向 §1.6。
- 新浪研报查北交所必须写 `bj920982`，只给数字会得到「没有找到」空页，看起来像该股没有研报。
- 质押统计全市场 2212 条没有一只北交所；北交所代码改为报错，不返回空表。
- 2022-05-06 之前的通达信盘后包没有北交所文件（二分实测 2022-05-05 没有、2022-05-06 有），原实现会整包报错。
  现在只对这之前的日期放行，之后缺北交所文件报错，不把沪深当成全市场。
- 盘后包不是只保留最近一段：最早能取到 2021-08-16（2021-08-02 返回 404），2022-01-04、2023-01-03 都能取到。
  11 个包里各市场有价记录的最小值为沪 16202、深 3641（2022 年以前深市大部分代码当日无价）、京 87，函数按沪 1 万 / 深 3000 / 京 50 设下限，
  代码表与行情块条数一致、代码和块序号都不重复、代码全是 6 位数字、价格与成交额没有 NaN / inf（11 个包实测均如此），函数对这几条都做了核对。
- 上交所 ETF 份额接口把每页压到 2000 条（请求 10000 也回 `pageSize=2000`），2026-09-18 共 912 条；函数要求条数等于 `pageHelp.total`。
- 新浪研报每页序号都从 1 编起；翻过末页、以及没有研报的股票，页面都写「没有找到相关内容」。上证e互动问答为空时，公司维度写「近1个月暂无回复 / 暂无提问」，
  全市场翻过末页写「暂时没有问答内容」。华尔街见闻宏观日历 31 周 5976 条没有重复 id。
- 中金所、广期所的数据地址只能走 HTTP：2026-09-20 用 curl 8.7.1 与 Python requests 实测，中金所 443 握手即断（SSL_ERROR_SYSCALL），
  广期所 443 返回的是 `*.unionpayintl.com` 的证书。交易日靠来源自己核对：中金所日行情 / 期权用同目录 `index.xml`，持仓排名用行内交易日，广期所用回显的请求参数。
- 通达信 F10 只剩「最新提示」一类（内置 10 台服务器逐台实测）。§6.2 示例原来写死 9 个类别名，请求不存在的类别时 mootdx 返回 dict，
  切片直接 TypeError；现改为先用 `F10C` 列出实际类别，`tdx_client(check='finance')` 同时核对财务快照、类别表里有「最新提示」、并实际读出非空正文（000001 实测 21494 字）。
- 上金所行情 7 个品种约 1.5 万条记录价格全是数字，无成交的时段填 0；函数剔除 0，空值 / NaN 报错。
- 广期所返回里没有 `delivMonth` 的只有小计 / 总计行（2022-12-22、2026-09-18 实测；周六只回一行总计），合约行缺这个字段报错，不当成非交易日。
