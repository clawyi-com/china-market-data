# 故障排查

仅在调用失败、返回空结果或历史数据不足时读取对应条目。正常取数按 [SKILL.md](../SKILL.md) 的端点路由执行；下文 § 编号均指该文件。历史实测记录不保证当前接口可用。

## 东财 403、429、连接重置或连续空结果

这些现象可能来自限流、风控、网络或上游变化，不能只凭一次错误认定 IP 被封。不同子域的影响范围可能不同：文档的 2026-06-30 案例中 push2/push2his 受影响，datacenter-web 未受影响。

1. 停止对失败端点持续重试，检查错误与请求频率；不要并发启动多个 CLI 绕过间隔。
2. 批量任务使用脚本已有的限流入口；支持 `--min-interval` 的命令可按帮助调大间隔。Python 调用修改 `_eastmoney.EM_MIN_INTERVAL` 模块属性。限流状态只在同一进程内共享。
3. 需要继续取数时，查主文件「备用源速查 & 降级策略」，核对备用源的市场、日期与字段覆盖。表中部分条目只有接口 URL，并非现成 CLI。

不承诺等待固定时长或换网络即可恢复；备用源也可能不可用。沪市公告备用仍走东财，不属于独立风控来源。

## mootdx 无法取数或海外连接超时

CLI 的 finance、F10C、F10 自动使用财务验活；Python API 使用 `tdx_client(check='finance')`。客户端已内置选服与 BESTIP 问题规避，无需另行裸调用 `Quotes.factory()`。

2026-09-20 的实测记录显示，行情命令返回空而财务和 F10「最新提示」可用。遇到相同表现，按 §1.7 的替代入口取行情；不要仅靠更换 mootdx 版本处理服务端空结果。全部候选服务器验活失败会报错，耗时取决于网络和测速。

mootdx 使用 TCP 7709，海外网络可能超时。检查网络可达性；需要替代时按具体数据能力选源，不能假设 HTTP 来源一定可用。

## iwencai 401 或结果条数少

检查 `IWENCAI_API_KEY` 及 `IWENCAI_BASE_URL` 配置。随附脚本已添加 X-Claw 请求头；401 时检查凭据、服务地址及错误响应，不必先重写请求头逻辑。Python 模块导入时读取环境配置，修改后需重启进程或显式修改模块配置。

`iwencai_search()` 与 CLI 的 `search --size` 当前默认均为 50；条数少不一定是参数限制，也可能是匹配结果不足。参数见 `scripts/iwencai.py search --help`，接口说明见 §2.3。

## 一致预期 EPS 为空、报错或表格不匹配

不能直接判定“没有机构覆盖”。§2.2 的实现会解析 HTML 表格，并在未匹配到目标列时回退首张表；请求失败、页面变化、选表偏差和确实无覆盖都需要区分。核对返回列、年度、机构数量和预测口径后再使用。

可查看 §2.1 东财研报中的 `predictThisYearEps`，但单篇研报预测不等于机构一致预期，需标明机构、报告日期和预测年度，不能无说明替代。

## 东财研报 PDF 下载 403

随附 `download_pdf()` 已设置 `Referer: https://data.eastmoney.com/` 并经过 `em_get()`。使用该入口仍失败时，核对报告下载地址与错误响应，再按东财故障条目处理；不要把补 Referer 当作保证有效的修复。调用方式见 §2.1。

## 投资者问答为空

先核对市场：深市使用 §10.1 巨潮互动易，沪市使用 §10.3 上证 e 互动。再核对查询条件、时间范围和响应结构；合法空结果可能表示该范围内没有记录，不能把错市场或接口异常当作“公司未回复”。

## 北向历史只有几天或完全为空

`history` 只读本地已采集的 CSV，不补抓历史。`realtime` 默认不写缓存；显式传 `--save-date` 或调用 `save` 才保存。日期必须核对，不能把示例日期用于实际采集。

`--save-date` 使用最后一个完整分钟点，不保证是收盘值；深股通序列缺失会影响可保存点。保存规则、数据可靠性和缓存路径见 §3.2。

## 编码、字段或响应类型异常

随附脚本已处理腾讯 GBK 解码、腾讯字段 43=振幅与 46=PB，以及百度 ResultCode 的整数/字符串成功码。使用 CLI 时直接读取解析后的命名字段，无需重复实现这些步骤。

若结果仍异常，保留命令、错误和响应结构用于排查；字段与单位见 §1.1、§1.5。勿以退出成功或非空结果单独判断数据正确。
